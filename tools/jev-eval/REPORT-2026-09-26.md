# Chat intent comparison — 2026-09-26

**Decision: keep hierarchical routing disabled.** It reduced tokens but did not reduce
ASKs or improve command selection in these runs. Do not merge semantically different
commands or lower thresholds merely to inflate confidence.

Model returned by all evaluated calls: `jev-1.13.0`. One run per case and strategy;
ACT/ASK thresholds remained 0.75/0.45. No player-confirmed records were found in current
or archived logs. These results are development evidence, not production accuracy.

## Forty synthetic explicit-command cases

| Strategy | Correct candidate command | ASKs | Wrong automatic actions | Mean input tokens |
|---|---:|---:|---:|---:|
| Flat, no averaging | 40/40 | 0 | 0 | 3,443 |
| Four-order averaging | 40/40 | 0 | 0 | 12,446 |
| Category then branch | 39/40 | 5 | 0 | 1,529 |

The 30 development cases were classified correctly by all strategies. On the ten
contrastive holdout cases, flat and averaging matched all labels; hierarchy matched
nine. Hierarchy interpreted “Stop healing but keep following” as `follow me` and ASKed
instead of selecting `heals off`. The category prompt was not retuned on that holdout.

Hierarchy saved about 56% of input tokens but needed a second sequential request for
commands. Development median latency: flat 192 ms, averaged 250 ms, hierarchy 332 ms;
holdout: 200 / 240 / 333 ms. These are single-run timings, not latency guarantees.

## Fourteen earlier log phrases with assistant annotations

Original context is unavailable. Ambiguous wording has multiple acceptable commands;
the proposed labels need human review and must not be called player confirmations.

| Strategy | Correct candidate command | ASKs | Wrong automatic actions | Mean input tokens | Median time |
|---|---:|---:|---:|---:|---:|
| Flat, no averaging | 12/14 | 5 | 0 | 3,398 | 192 ms |
| Four-order averaging | 13/14 | 3 | 0 | 14,077 | 266 ms |
| Category then branch | 11/14 | 5 | 0 | 1,051 | 331 ms |

Averaging recovered the annotated stop/logout interpretation of “thanks pal, go get
some rest, we're done for today”, but still asked for confirmation. Every strategy
missed the provisional stats/range interpretation of “how tough are you these days?”.
Hierarchy additionally ignored “stop attacking”.

The averaged strategy includes its narrow re-ask when the first decision is ASK;
it averaged 1.21 requests per challenge case. This is NOT the current production
exempt-full-request/SHADOW policy. Compare token costs using the recorded calls rather
than assuming every strategy sends one request. Averaging's confidence is winning mean
probability, whereas the unaveraged API confidence is its own statistic.
